# Repository Instructions

## Post-Edit Workflow
Whenever you finish modifying, creating, or refactoring code files in this project:
1. Immediately ask me: *"Changes are complete. Would you like me to commit and push these updates directly to GitHub?"*
2. If I say yes or confirm:
   - Run `git status` and `git diff` to inspect changes.
   - Stage all changes with `git add .`
   - Create a concise, meaningful commit message based on the edits made: `git commit -m "<concise description>"`
   - Push to GitHub: `git push origin main`
3. Confirm once the push is successful.
